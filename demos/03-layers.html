Stacking filters: from edges to shapes to a few numbers

A convolutional neural network repeats the same steps: filter, keep the strong responses, shrink. Notice how during each round the number of pixels (neurons) shrinks until we arrive at two outputs, which feed the classifications. Each map is a different filter, and each filter looks for a different feature. The first layer finds edges, the next layer finds shapes, and the last layer finds patterns that are diagnostic of melanoma. Hover over any map to see which part of the image it is looking at, and how big the receptive field is.
